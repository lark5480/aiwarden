## 序列之间的关系

```
01 资产盘点 ─┐
02 市场缺口 ─┼→ 04 选题论证 ──→ PRD v1.0 ──┐
03 竞品调研 ─┘                              │
                                            ↓
                                 05 独立验证（三方交叉质询）
                                            ↓
                                 06 裁决清单（13 条）──→ PRD v2.0 回写
```

- **05 对 01–04 与 PRD v1.0 做独立验证**，并明确记录**被推翻的结论**（如 01 §3.1 G1 的「35% 岗位」口径、RuoYi-AI「官方自认」表述、MaxKB4j dualWrite 证据）——它把「自己论证自己批准」这一层堵掉了；
- **06 是 PRD 回写的唯一依据**，13 条裁决逐条给出【裁决】【理由】【落到 PRD 的动作】；
- **01–04 不回改**——被推翻的表述以 06 号文档校准为准。这是有意的：保留「当时为什么会这么判断」的痕迹，而 06 记录「后来为什么改了」。

## 两处必须知道的口径细节

1. **两套命中率口径不同源，不要混用**：04 §二的「**12/14**」基于第一组 14 项广度清单；06 引用的「**6/13**」基于第二组统一后的 13 项缺口矩阵。**对外一律按 6/13 并注明出处**（见 06 附录 3）。
2. **06 是「裁决已定」的记录，不是「已经改了」的证明**。PRD 是否已按某条裁决回写，要看 [`../PRD.md`](../PRD.md) 正文与该条的落点是否一致——**两边不一致时，以 PRD 正文为准并回来补 06 的状态**。
